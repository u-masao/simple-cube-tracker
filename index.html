使い方・メモ

    
    
      
  • 対応ブラウザ: Android の Chrome、Windows の Chrome / Edge（Web Bluetooth 対応ブラウザ）。iOS の Safari は非対応です。
    • 
      
  • このページは HTTPS で開いてください（GitHub Pages ならそのまま条件を満たします）。file:// では Bluetooth が使えません。
    • 
      
  • 接続 を押すとブラウザのデバイス選択ダイアログが出ます。キューブを操作して起こしてから選んでください。
    • 
      
  • MAC アドレスを自動取得できない端末では入力を求められます。Android の Cube Station アプリの端末情報や nRF Connect などで確認できます（一度入力すると端末名ごとに保存されます）。
    • 
      
  • 出力は時系列のテキストです。コピー または ダウンロード して LLM に貼り付けてください。API 連携はありません。
    • 
      
    •
